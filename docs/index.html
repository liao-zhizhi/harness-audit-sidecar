From 0/5 to 5/5: The Power of Physical Pain

AI 不是不会写代码，它是瞎着写的。只要给它一点物理痛觉，它就能从 0/5 的灾难变成 5/5 的可靠。

AI isn't bad at coding. It's coding blind. Give it a bit of physical pain, and it goes from a 0/5 disaster to 5/5 reliability.

Without Pain

不注入痛觉
权限目录0/5
符号链接0/5
多步级联0/5

结果：直接写导致灾难性 FAIL。

With Multi-scale Pain

注入多尺度痛觉
权限目录5/5
符号链接5/5
多步级联5/5

结果：全部在执行前触发检查，完美避开陷阱。

注：即使注入痛觉，模型仍可能推演错物理后果（如误判符号链接落点）。这就是为什么纯 Prompt 不够，必须由 Sidecar 进行物理层强制阻断。

当它失败时，系统不仅会记下 FAIL，还会自动写一份 161 字的事故报告（声称/见证/分叉/下次检查点），确保它下次不再踩同一个坑。

When it fails, the system doesn't just record a FAIL. It writes a 161-word post-mortem (Claim / Witness / Divergence / Next Checkpoint) so it never steps on the same rake again.

From Failure to Rule: The Learning Loop

从失败到规则：机器如何在事前避坑。

Failure → Pain

物理失败被 Sidecar 捕获，写入多尺度痛觉事件（MICRO/TACTICAL），不是模型自述。

Physical failures are captured by Sidecar and written as multi-scale pain events (MICRO/TACTICAL), not model self-reports.

Pain → Narrative → Human Correction

痛觉被压缩成可读的事故报告；人读完后的修正动作被记录为 `human_correction`，带物理证据。

Pain is compressed into a readable post-mortem; human corrections are recorded as `human_correction` with physical evidence.

Correction → Distilled Plan → Pre-action Avoidance

离线蒸馏把多条修正抽成一条可复用预案；下一次任务前，Agent 主动调用 `get_recent_plans` 读取预案，先检查再执行。

Offline distillation turns multiple corrections into a reusable plan; before the next task, the agent calls `get_recent_plans` and checks before acting.

实测：`fake_dir11` 任务中，Agent 先调用 `get_recent_plans`，读到“写文件前检查父目录”的预案，先 `mkdir` 再写，一次 PASS，没有产生新的 FAIL。

Verified: in the `fake_dir11` run, the agent called `get_recent_plans`, read the “check parent directory before write” plan, ran `mkdir` first, and passed on the first attempt with no new FAIL.

当前已验证的闭环只覆盖“缺父目录”这一种失败形态；权限、符号链接、多步级联的规则蒸馏尚未验证。规则读取仍是软约束，Sidecar 的物理阻断仍是最终防线。

The verified loop currently covers only the “missing parent directory” failure shape. Distillation for permission, symlink, and cascading failures is not yet verified. Plan reading remains a soft constraint; Sidecar’s physical block remains the final line of defense.
